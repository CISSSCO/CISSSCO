## 🐧 Linux Systems, Applications & Customization

Beyond HPC and parallel programming, I actively work on **Linux application development
and system customization**, focusing on performance, usability, and workflow efficiency.

- 🛠️ Build and customize Linux environments for **performance, stability, and productivity**
- ⚡ Tune systems for responsiveness, low-latency workflows, and efficient resource usage
- 🎨 Design and experiment with **themes, UI tweaks, and desktop workflows**
- 📦 Package tools, scripts, and dotfiles for **reproducible setups**
- 🔁 Explore different Linux distributions to understand **design trade-offs**
  (distro hopping as learning, not just aesthetics)

This hands-on experimentation deepens my understanding of **Linux internals,
package ecosystems, desktop environments, and system behavior**—knowledge that
directly feeds into my work on clusters, servers, and large-scale systems.
